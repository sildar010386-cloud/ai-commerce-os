# office/ — 3D-панель офиса команды

Одна самодостаточная страница `index.html` (Three.js 0.160.0 с CDN jsdelivr): 3D-офис, где работают 8 сотрудников. Нажатие на сотрудника открывает карточку: чем занимается и как работает.

## Как изменить сотрудников

В `index.html`: объект `INFO` (имя, роль, статус, цвет, пункты, описание), объект `P` (внешний вид и параметры фигур), раскладки `LAY` (позиции столов для режимов wide / phone и др.), `buildGraph` (точки маршрутов, по которым ходят люди). После правки проверить маршруты: `checkPaths()` и `minSep` (минимальная дистанция между людьми) вызываются через `window.__sim` (`step`, `advance`).

## Как проверить локально

Отдать папку любым статическим сервером (например `python3 -m http.server`), открыть страницу через Playwright и перехватить (route) запросы к jsdelivr, подставляя `three@0.160.0` из `node_modules`. Затем прогнать симуляцию через `window.__sim` и убедиться, что `checkPaths` и `minSep` проходят.
