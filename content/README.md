# content/ — очередь и черновики органики

- Чей код: данные проекта органики (не код). Тексты Threads, сценарии reels, карусели, референсы, статистика, голос и музыка.
- Что внутри: `queue/<дата>.json` — очередь публикаций (читает `tools/publish/`), `threads/`, `reels/`, `carousels/`, `refs/`, `stats/`, `comments/`, `raw*/` и др.
- Можно ли трогать: черновики и очередь правит только дирижёр по команде владельца; имена папок и формат `queue/*.json` не менять — на них завязана публикация.
- Кто деплоит: никто, файлы читают скрипты `tools/` и Actions. Правила контента — `docs/content/RULES.md`.
- Данные клиентов и реклама сюда не попадают (репозиторий публичный).
