# Фоновая музыка

- Треки лежат в **закрытом** репозитории `sildar010386-cloud/bikas-music` (Pixabay Music; лицензия запрещает раздавать файлы отдельно, поэтому не в этом публичном репозитории).
- `catalog.json` — характеристики треков (`tools/music/catalog.py`): длина, темп (оценка, может быть ×2/÷2), громкость LUFS, яркость, громкость первых 3 секунд, тихие секунды.
- Сведение (REEL-01, проба 2026-09-30): трек → loudnorm −20 LUFS, fade in 0.3 с / out 2 с → EQ −4 дБ на 1.5 кГц, highpass 45 Гц, volume 0.65 → sidechaincompress по голосу (threshold 0.06, ratio 2.5, attack 30, release 400). Итог: музыка ≈16 дБ тише голоса во время речи.
- Не повторять один трек в соседних роликах; дубликат `lnplusmusic…597024 (1).mp3` не использовать.
