## Откуда кадры и главное ограничение
- Сырьё (GitHub Release `raw-01..03`) скачать из сессии нельзя: `gh release download` блокируется (GraphQL), `raw-04/05` в релизах нет. Поэтому кадры вытащены из **готовых роликов** `content/reels/REEL-NN/*.mp4` (1080x1920).
- В готовых роликах вшиты субтитры (у большинства роликов на ~66% высоты, у REEL-42…47 на ~80%) и верхние плашки. Поэтому новые кадры **обрезаны** до чистой зоны (колонка «кроп»). Все 16 годных новых кадров проверены глазами: ни субтитров, ни плашек внутри кадра нет.
- Размер кадров 1080 x (740…1480). Для слайда 1080x880 (как K-02/src/p*.jpg) подходят все; для поста Threads — тоже, кроме узких по высоте (f15).
- Резкость: «Лаплас» (чем выше, тем резче; для сравнения K-02/p3 = 376, K-02/p2 = 1177, T-81_s5 = 44). Кадры из ранних роликов (REEL-01…13, снято на raw-01…03, исходник 464p по README raw-03) мягче, это видно в крупном плане. Для превью поста нормально, на весь экран хуже.
