# scripts/ — скрипты установки сервера

- Чей код: бот приёмки `app/` (parked).
- Что делает: `install.sh` ставит бота на VPS, `update.sh` обновляет (git pull + docker compose), `logs.sh` показывает логи, `set_owner.sh` задаёт владельца.
- Можно ли трогать: нет, пока сервер не одобрен владельцем.
- Кто запускает: владелец на сервере; сейчас не используется.
