## Папки с кодом (не переносить: на пути опираются автоматизации)

| Папка | Что это |
|---|---|
| `tools/` | Автоматизация органики: публикации, статистика, видео, Telegram, Threads, TikTok, Instagram, CRM-синхронизация |
| `crm/` | CRM на Cloudflare Worker + D1; деплой Actions «CRM deploy» из `crm/cf` |
| `connector/` | Коннектор WhatsApp; ноутбук владельца обновляется из этой папки автоматически |
| `content/` | Очередь публикаций (`content/queue/*.json`) и черновики |
| `spybot/` | Копия воркера бота-разведчика из `bikas-target`; деплой «Spy bot deploy» |
| `app/` | Telegram-бот приёмки сырья; припаркован, не разворачивать |
| `scripts/` | Скрипты установки сервера для `app/` |
| `tests/` | Тесты `app/` (`pytest`) |
| `office/` | 3D-страница офиса команды (одна HTML-страница) |
| `docs/index.html`, `privacy.html`, `terms.html`, `tiktok*`, `docs/tiktok/`, `docs/assets/`, `docs/refs/` | GitHub Pages и проверка TikTok: не трогать и не переносить |

## Куда что сохранять

- Органика — только в этот репозиторий (`ai-commerce-os`).
- Реклама — только в `bikas-target` (закрытый).
- Юридическое — только в `bikas-legal` (закрытый, создан 2026-11-12).
- Ипотека и финансы — только в `finance-ipoteka` (закрытый, создан 2026-11-12).
- Секреты — только в `bikas-music/secrets` (закрытый), GitHub Secrets и переменные среды; никогда не в этот репозиторий.
- Персональные данные клиентов — никогда в этот публичный репозиторий.
