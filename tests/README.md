# tests/ — тесты бота приёмки (app/)

- Чей код: тесты для `app/` (pytest, `pyproject.toml`: `testpaths = ["tests"]`).
- Что делает: проверяют диалог бота, приёмку и сводки; идут на SQLite, при желании на PostgreSQL.
- Можно ли трогать: не переносить, иначе сломается `pytest`. Запуск: `pip install -e ".[dev]" && pytest`.
- Кто запускает: разработчик/Claude перед изменениями кода; деплоя нет.
- Тесты CRM лежат отдельно: `crm/cf/test/`, тесты коннектора — `connector/test/`.
