# Сборка роликов с персонажем владельца (REEL-54, REEL-55) — скрипты

Это рабочие скрипты, которыми собраны одобренные ролики REEL-54 и REEL-55 (31.10–01.11.2026). Они писались в /tmp сессии,
поэтому пути внутри жёстко заданы (/tmp/facework/reel01|reel02, /tmp/fm, /tmp/px). В новой сессии: создать эти папки заново
или поправить пути в начале файлов. Секретов в скриптах нет (ключ ElevenLabs подставляет прокси).

Порядок (ролик №2, `REEL-55`):
1. `tts2.py` — озвучка одним дублем: ElevenLabs «Мой голос 2» (пресет owner2 в tools/video/tts.py: speed 1.03, style 0), with-timestamps → mp3 + слова.
2. `stt.py` — проверка распознаванием (ElevenLabs scribe_v1): все слова на месте, лишних нет; иначе другой seed.
3. `plan.py` — план кадров: какая фраза → поза персонажа или живой кадр raw-01…06, заголовок на весь ролик, акценты субтитров, SFX.
4. `build_poses.py` + `lm_all.py` + `landmarks.py` — точки лица (mediapipe FaceLandmarker, модель face_landmarker.task с
   storage.googleapis.com) и сборка поз: основа «рот закрыт», рот из «открыт», глаза из 01g (моргание), чтобы голова/руки не прыгали.
   Позы — приватный `bikas-music/avatar/poses/` (в публичный репозиторий не класть).
5. `render.py` — кадры 1080×1920 30 fps (PIL → ffmpeg): заголовок на всё видео в зоне 3:4, персонаж/кадры, кружок-персонаж на вставках,
   субтитры по правилам Армана, рот по громкости (closed/half/open), моргание.
6. `audio.py`, `mix.py` — SFX (25–30 на ролик) + музыка (catalog.json, не повторять трек соседнего ролика, −15 дБ, sidechain),
   alimiter → loudnorm −14 LUFS / TP −1, без шумодава.
7. `sheet.py` — контрольный лист 12 кадров для проверки Opus.
Python-окружение: venv с mediapipe, opencv-python-headless, pillow, numpy, fonttools (+ apt libegl1 libgles2 для mediapipe).
Шрифты: Montserrat (tools/tiktok/fonts, woff2 → ttf через fontTools).
Правила, которые владелец требует (DECISIONS 31.10–02.11): заголовок = первые слова, весь ролик; слова = картинка (нет кадра —
персонаж); живых кадров ≥ половины; без «!» в тексте для озвучки; чистовик сразу в бот; подпись TikTok — отдельным сообщением в бот.
