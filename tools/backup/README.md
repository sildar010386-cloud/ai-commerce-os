# Резервная копия всех хранилищ на ваш компьютер

Зачем: если заблокируют Claude или GitHub, у вас на компьютере останется полная копия всех 5 хранилищ — со всей историей. Любой другой ИИ (Codex и др.) сможет продолжить работу по этим файлам (вход — `CLAUDE.md` / `AGENTS.md` в каждом хранилище).

| Хранилище | Что внутри |
|---|---|
| ai-commerce-os | органика, CRM, правила, офис |
| bikas-target | реклама, история старых чатов |
| bikas-legal | юрист: земельные отношения и гражданское дело |
| finance-ipoteka | ипотека (Нурлан) |
| bikas-music | ключи, музыка, аватары |

## Настройка (один раз, ~10 минут)
1. Установите Git (бесплатно): https://git-scm.com/download/win — скачать, установить, все кнопки «Next» по умолчанию.
2. Скачайте эту папку на компьютер (4 файла: `backup.ps1`, `install_weekly.ps1` и два `.bat`), положите, например, в «Документы\AI_Backup_tools».
3. Дважды нажмите **`1_ВКЛЮЧИТЬ_еженедельную_копию.bat`**. При первом запуске откроется окно входа в GitHub — войдите своим аккаунтом (один раз, дальше Windows запомнит).
4. Дождитесь «Готово: успешно 5, ошибок 0». Первая копия ai-commerce-os большая (около 1,5 ГБ) — может занять 10–30 минут.

## Дальше — само
- Каждое воскресенье в 13:00 копия обновляется сама (если компьютер был выключен — при следующем включении).
- Сделать копию вручную: дважды нажмите **`2_Сделать_копию_сейчас.bat`**.
- Где лежит: «Документы\AI_Backup»: `readable\` — обычные папки с файлами (можно открыть и читать), `mirrors\` — полная копия со всей историей, `backup_log.txt` — журнал копий.
- Скрипт ничего не удаляет и никуда ничего не отправляет: только скачивает.

## Если что-то не так
- «не установлен Git» — шаг 1.
- «ОШИБКА bikas-legal …» или другое закрытое хранилище — войдите в GitHub в окне, которое откроется, или проверьте, что вы вошли своим аккаунтом.
- Пришлите Арману последние строки `backup_log.txt`.
