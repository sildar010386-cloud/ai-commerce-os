# Публикация: проверенный порядок (правила из реальных ошибок)

Любая публикация — только после «да» владельца на этот конкретный пост (текст, картинки/видео, подпись).

## Threads — ветка из N постов

Скрипт: `tools/threads/publish_thread.py CODE SHA` (черновик в `content/threads/CODE/README.md`, разделы «## Пост N — `картинки.jpg`»).

1. Картинки закоммитить и запушить; ссылки — `raw.githubusercontent.com/.../<SHA коммита>/...` (проверить, что отвечают 200).
2. Первый пост — обычный; **каждый следующий — ответом на предыдущий, параметр `reply_to_id`** (не `reply_to_message_id`: его Threads молча игнорирует и публикует отдельный пост — ошибка T-01, 2026-09-30).
3. После каждого ответа скрипт проверяет `is_reply` и `replied_to` = предыдущий пост; если нет — останавливается.
4. После публикации: `published.json` (ID всех постов), проверить цепочку ещё раз, статистика через 24 ч.
5. Удалять посты через API нельзя (нет права `threads_delete`) — при ошибке сообщить владельцу, он удаляет вручную. Продолжить цепочку: `publish_thread.py CODE SHA PARENT_ID START_N`.

## Instagram — Reels

Скрипт: `tools/instagram/publish_reel.py VIDEO_URL CAPTION.txt OUT.json`.

1. Загрузка файла напрямую (`upload_type=resumable`) для нашего токена (вход через Instagram) **не работает** — нужна публичная ссылка `video_url`. Одобренный MP4 коммитим в `content/reels/CODE/` и берём ссылку на коммит.
2. Файл должен быть ровно тем, что одобрил владелец (сверить время/хэш).
3. Подпись — из `README.md` ролика, без изменений.
4. Музыку из библиотеки Instagram через API добавить нельзя — музыка вшивается в файл при сборке (CONTENT_PLAYBOOK §12).
5. После публикации: проверить ролик и подпись через API, записать `published.json`.

## Instagram — Stories

Тот же скрипт с `--story`: `media_type=STORIES`, подпись не используется. Видео 9:16, до 60 сек. Ссылки/стикеры через API не добавляются. Нижнюю часть кадра в Stories перекрывает строка ответа — важный текст держать выше.

## Связка Reels → Stories

**Решение владельца 2026-09-30:** после публикации одобренного Reels тот же ролик **сразу публикуется в Stories без отдельного вопроса** (одобрение Reels = одобрение его Stories). Первый раз: REEL-01 с музыкой, 2026-09-30.
