# План роликов на неделю №1 (новый подход, черновик на одобрение владельцу)

Основа: курс по продающим Reels и решения владельца (DECISIONS 2026-10-09).
- **3 ролика в день: 1 продающий + 2 охватных.** За неделю 21 ролик: 7 продающих, 13 охватных, 1 личный (≈5 %).
- **Три ролика дня — три разных формата**, ни один не повторяет формат вчерашнего дня. За неделю 12 форматов.
- Только русский, закадровый женский голос, без цены. Субтитры — HyperFrames.
- Призыв продающих: «Напишите «ПАР» в комментариях — ответим в личные сообщения». Охватных — вопрос в комментарии, «сохраните» или «часть 2 завтра».
- День 1 — первый день после того, как придёт новое сырьё.

## Неделя

| День | Продающий | Охватный 1 | Охватный 2 |
|---|---|---|---|
| 1 | **Демонстрация:** мятая рубашка за 5 минут до выхода | **Вопрос-игра:** «Где прошёл пар — слева или справа?» | **Советы:** «3 вещи, которые нельзя гладить утюгом» |
| 2 | **До / после:** пододеяльник прямо на кровати | **Короткий луп POV** 7–10 с: «POV: выходить через 5 минут» | **Сериал, часть 1:** «Отпариваю всё в шкафу — шторы» |
| 3 | **Сравнение:** утюг с доской против ручного отпаривателя, честно | **Миф / антисовет:** «Не гладьте тёмные вещи утюгом напрямую — останется блеск» | **Эстетика / ASMR:** пар крупным планом, без голоса, музыка |
| 4 | **Комплект / распаковка:** что в коробке, держатель на стену | **Вопрос-игра:** «Какую ткань нельзя отпаривать?» | **Сериал, часть 2:** «Отпариваю всё в шкафу — пиджак» |
| 5 | **Проверка:** «Разгладит ли мокрый лён / пиджак?» | **Короткий луп POV:** «Когда гладильная доска больше не нужна» | **Советы:** «Как отпарить шторы, не снимая с карниза» |

| 7 | **До / после:** самая мятая вещь недели | **Тренд:** трендовый звук + отпаривание (владелец выкладывает со звуком из приложения) | **Миф:** «Отпариватель не для плотных тканей?» |

Суббота — разбор недели: какие ролики дали комментарии, директ и заявки; что повторить, что убрать.

## Структура каждого формата (по секундам)

Продающие идут строго по формуле владельца: **зацепка → боль → решение → уникальность → призыв**. Меняется подача — формат. Охватные строятся по своим структурам: их задача — досмотр, сохранения, репосты и комментарии, а не продажа.

**Продающие (15–25 с, новый кадр каждые 1,5–2 с)**
1. **Демонстрация.** 0–2 с: мятая вещь крупно + текст-ситуация («Выходить через 5 минут?») → 2–4 с: боль (доска, утюг греется) → 4–11 с: пар — складки уходят одним дублем → 11–14 с: уникальность (ручной, на вешалке, держатель на стене) → 14–17 с: «Напишите «ПАР»…».
2. **До / после.** 0–1,5 с: сразу результат — экран пополам «было / стало» → 1,5–3 с: «Как?» → 3–10 с: процесс, быстрый монтаж → 10–12 с: снова результат → призыв.
3. **Сравнение.** 0–2 с: вопрос-вызов («Утюг или отпариватель — что быстрее?») → две половины экрана с таймером → честный итог: где удобнее утюг, где отпариватель → призыв.
4. **Комплект / распаковка.** 0–2 с: коробка + «Что внутри за…» → каждая деталь крупно по 1,5 с → держатель на стене — главный момент → призыв.
5. **Проверка.** 0–2 с: сомнение («Разгладит ли пиджак?») → ставка («Спорим?») → процесс → вердикт крупно → призыв + «что проверить следующим?».

**Охватные (7–15 с)**
6. **Вопрос-игра.** 0–1 с: вопрос + две половины → 2 с паузы: зритель думает и пересматривает → ответ → «угадали? пишите».
7. **Короткий луп POV.** Один кадр, текст-ситуация сверху, 1 фраза голосом или без голоса; конец склеен с началом, чтобы ролик пересматривали.
8. **Советы.** 0–2 с: обещание с числом («3 вещи…») → пункт 1, пункт 2 → «третий удивит» (держит до конца) → «сохраните».
9. **Миф / антисовет.** 0–2 с: «Не делайте так» + кадр ошибки → почему → как правильно → вопрос в комментарии.
10. **Эстетика / ASMR.** Пар, ткань, свет у окна; без голоса, музыка, одна строка текста.
11. **Сериал.** 0–1 с: «Часть N» + вещь → отпаривание → «Завтра — часть N+1: …» (повод подписаться).
12. **Личный.** Утро руками и голосом от первого лица: кофе → рубашка на вешалке → пар → выход из дома.
13. **Тренд.** Трендовый звук дня + короткое отпаривание под ритм; звук добавляет владелец в приложении.

## Что снять под эту неделю (сырьё)

Телефон вертикально, 1080p или 4K, дневной свет у окна, без звука, присылать файлом. Каждая вещь: сначала 3–5 с мятой без движения, потом весь процесс одним дублем, потом 3 с результата. Для «до / после» — телефон на подставке, кадр не двигать.

1. Рубашка (чёрная или белая), очень мятая, на вешалке.
2. Пододеяльник, застеленный на кровати.
3. Утюг с доской + отпариватель на одной рубашке, с таймером на телефоне — для сравнения.
4. Коробка с комплектом: открыть, достать каждую деталь; повесить держатель на стену.
5. Пиджак и льняная вещь (лён можно слегка сбрызнуть водой).
6. Шторы на карнизе.
7. Платье или блузка.
8. Куртка или другая плотная вещь.
9. Две одинаковые ткани: одна отпарена, другая мятая — для вопроса-игры.
10. Утро: чашка кофе, рубашка на вешалке, руки берут отпариватель, выход из дома (без лица).
11. Пар крупно на фоне окна — 10–15 с для эстетики.
