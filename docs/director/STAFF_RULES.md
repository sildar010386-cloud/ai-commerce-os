## Жёсткие правила для всех сотрудников
1. **Только своя папка.** Писать и менять файлы — только в папках из таблицы. Читать можно всё, что нужно для задачи. В чужую папку не писать даже «для пользы» — сказать Арману.
2. **Защищённые папки — никогда не менять** (ломается работающая система): `crm/`, `connector/`, `tools/`, `spybot/`, `office/`, `app/`, `scripts/`, `tests/`, `.github/`, `.claude/`, `CLAUDE.md`, `AGENTS.md`, `MAP.md`, `docs/director/`, `docs/index.html`, `docs/privacy.html`, `docs/terms.html`, `docs/tiktok/`, `docs/assets/`; в `bikas-target` — `spy/`, `worker/`, `.github/`, `CLAUDE.md`; в `bikas-music` — всё (особенно `secrets/`). Нужна правка там — описать её Арману, решает он с владельцем.
3. **Без commit, push, смены веток и удаления файлов.** Только Арман смотрит изменения (`git diff`) и сохраняет. Удалять файлы нельзя — только сообщить.
4. **Ничего наружу.** Не публиковать, не писать в бот, не отвечать клиентам, не запускать Actions, не тратить платные кредиты, не входить в рекламные кабинеты — только Арман по команде владельца.
5. **Ничего без ведома владельца.** Не менять правила, решения, цены, расписание, очередь (`approved`) и модели. Свои правила не вводить — работать по `docs/director/DECISIONS.md`.
6. **Секреты.** Ключи и пароли не печатать, не копировать, не класть в файлы. Клиентские и личные данные — никогда в публичный `ai-commerce-os`.
7. **Факты.** Каждое утверждение — с цифрой и источником; догадку помечать «догадка».
8. **Отчёт Арману.** В конце: что сделано, какие файлы изменены (пути), что не получилось. Арман проверяет по `docs/director/QA_CHECKLIST.md` до отправки владельцу.

## Как Арман проверяет перед сохранением
- `git status` и `git diff --stat`: изменённые файлы только в папке сотрудника. Если затронута защищённая папка — откатить (`git checkout -- путь`) и разобраться.
- После любых изменений рядом с автоматикой — ручной запуск Publish и проверка, что прошёл.
