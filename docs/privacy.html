Политика конфиденциальности — Bikas Home Publisher

Дата: 30 сентября 2026 г.

Bikas Home Publisher («инструмент») — внутренний инструмент магазина Bikas Home для публикации собственных видео магазина в его аккаунт TikTok и просмотра статистики этих видео. Инструмент не предназначен для посторонних пользователей.

Какие данные мы получаем

После входа владельца магазина через TikTok инструмент получает: базовые данные профиля (имя, аватар, идентификатор), статистику профиля (подписчики, лайки), список видео аккаунта и их статистику (просмотры, лайки, комментарии, репосты). Для публикации инструмент передаёт в TikTok видеофайлы магазина.

Как используем

Только для публикации контента магазина и анализа его результатов. Данные не продаются, не передаются третьим лицам и не используются для рекламы.

Хранение и удаление

Токены доступа хранятся в закрытых настройках рабочей среды владельца. Доступ можно отозвать в любой момент в настройках TikTok (Настройки и конфиденциальность → Безопасность → Управление разрешениями приложений). Для удаления данных напишите нам в Instagram @bikas.home.
