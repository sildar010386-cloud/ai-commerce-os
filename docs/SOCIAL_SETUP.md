# Подключение соцсетей к Claude

Всё бесплатно, только официальные API. Пароли и токены в чат не отправляем: токен владелец вставляет в настройки облачной среды Claude, Claude читает его из переменной окружения.

Порядок: Instagram → Threads → TikTok.

## Что будет возможно после подключения

| | Instagram | Threads | TikTok |
|---|---|---|---|
| Статистика каждого ролика/поста | да: просмотры, охват, лайки, комментарии, сохранения, репосты, среднее время просмотра | да: просмотры, лайки, ответы, репосты, цитаты | да: просмотры, лайки, комментарии, репосты |
| Статистика профиля | да: охват, подписчики, демография | да: подписчики, демография | да: подписчики, лайки |
| Публикация | Reels и посты, после одобрения владельца | посты и ветки | только после проверки приложения TikTok; до этого публикует владелец вручную |
| Комментарии | чтение и ответы | чтение и ответы | чтение |
| Шапка профиля (фото, имя, описание, ссылка) | **нет**: API не даёт. Claude пишет тексты, владелец вставляет | **нет** | **нет** |

Ограничения:
- Графика удержания по секундам нет ни в одном API. Для оценки хука: среднее время просмотра ÷ длина ролика; при необходимости — скриншот удержания из приложения.
- Reels через API публикуются без трендовой музыки из библиотеки Instagram (для роликов с озвучкой не важно).
- Токен Instagram и Threads живёт 60 дней. Claude заранее напомнит обновить.
- Claude работает в сессиях, не круглосуточно. Сбор статистики по расписанию — отдельная настройка (ежедневная сессия), позже.

## Шаг 0. Сеть среды (один раз для всех трёх)

Меню облачной среды в заголовке сессии → **Edit** → **Network access** → добавить в разрешённые домены:

```
graph.instagram.com
rupload.facebook.com
graph.facebook.com
graph.threads.net
open.tiktokapis.com
```

## Instagram

1. **Профессиональный аккаунт.** Instagram → Профиль → ☰ → «Настройки и конфиденциальность» → «Тип аккаунта и инструменты» → «Переключиться на профессиональный аккаунт» → «Бизнес» → категория (например, «Товары для дома»). Если аккаунт уже бизнес или автор — пропустить.
2. **Кабинет разработчика.** С компьютера открыть developers.facebook.com → войти через Facebook → «Начать» / зарегистрироваться как разработчик (подтверждение по телефону или почте).
3. **Приложение.** «Мои приложения» → «Создать приложение» → название `AI Commerce OS` → вариант использования **«Управление сообщениями и контентом в Instagram»** → тип «Бизнес» (если спросит) → создать.
4. **Токен.** В приложении: «Варианты использования» → Instagram → «Настроить» → **«Настройка API со входом через Instagram»** → раздел **«Сгенерировать маркеры доступа»** → «Добавить аккаунт» → войти в свой Instagram → разрешить все запрошенные права. Если Instagram попросит принять приглашение тестировщика: Instagram → Настройки → «Приложения и сайты» → «Приглашения тестировщиков» → принять. Затем в строке аккаунта нажать **«Сгенерировать маркер»** → скопировать.
5. **Сохранить токен в среде** (не в чат): меню среды → **Edit** → переменные окружения → добавить `IG_ACCESS_TOKEN=<токен>` → сохранить.
6. **Новая сессия** (настройки среды применяются к новой сессии) → написать Claude «Instagram подключён». Claude проверит профиль, список роликов и статистику.

Права, которые нужны: `instagram_business_basic`, `instagram_business_content_publish`, `instagram_business_manage_insights`, `instagram_business_manage_comments`.

## Threads

Делается в том же кабинете разработчика после Instagram. Подробные шаги — когда Instagram будет подключён. Переменная: `THREADS_ACCESS_TOKEN`.

## TikTok

Отдельный кабинет developers.tiktok.com. Для публикации через API TikTok проверяет приложение (нужны сайт, политика конфиденциальности, демо-видео); до проверки API публикует только приватно. План: сначала статистика через API, публикует владелец вручную из приложения (так же доступны трендовые звуки). Подробные шаги — после Threads.
