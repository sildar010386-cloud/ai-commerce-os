# Ежедневный цикл «пакет на завтра» (решение владельца 2026-10-01)

Время — Алматы (UTC+5). Канал с владельцем — Telegram-бот `@bikas_content_bot` (`tools/telegram/tg.py`).
Объём в день: **4 ролика** (Reels + Stories + TikTok) и **6 веток Threads** (каждая — ещё и карусель TikTok).

## 1. Вечер: сборка пакета (старт ~20:00, отправка к 22:00)

1. Подготовка сеанса: `bikas-music` (add_repo access=push, clone в `/home/user/bikas-music`), `pip install pillow`,
   исходники `raw-NN` из релизов в рабочую папку (см. `content/raw-*/README.md`, нумерация клипов raw-02 → 21, 22, 23…).
2. Статистика: `python3 tools/stats/daily.py` → выводы (2–3 пункта с цифрами) в `content/stats/LEARNINGS.md`.
3. Сборка на завтра по `docs/CONTENT_PLAYBOOK.md` §2, §3, §12, §13 и `docs/THREADS_PLAYBOOK.md`:
   - 4 ролика `REEL-NN` (форматы чередуются, хук — результат/интрига в первой секунде, 15–25 с, голос Larisa, музыка без повторов подряд);
   - 6 веток `T-NN` (2–3 поста, интрига в посте 1, ответ сразу в посте 2) + `Обложка TikTok:` в каждой → `tools/tiktok/carousel.py`.
   - Подписи: не больше 5 хэштегов. Карусели TikTok — без описания, последний слайд — призыв (доставка + WhatsApp). Видео TikTok — с подписью.
   - Факты о товаре только из DECISIONS (комплект: отпариватель на подставке, мерный стаканчик, защитная перчатка).
4. План публикаций → `content/queue/<завтрашняя дата>.json` (см. §3), всё закоммитить и запушить.
5. В 22:00 — в бот:
   - статистика за день (коротко: просмотры, среднее время просмотра Reels, дочитываемость веток, лучший/худший пост, вывод);
   - каждый ролик: `tg.py video` с подписью под ним;
   - каждая ветка: текст постов одним сообщением + `tg.py photos` слайды карусели;
   - график публикаций на завтра;
   - вопрос: «Одобряете? Можно ответить текстом или голосом: „всё ок“ или „1, 3 — да, 2 — переделать хук“».
6. Ждать ответа: `tg.py inbox` каждые 20–30 минут (самонапоминание `send_later`) до 03:00.
   Правки — переделать и прислать заново только изменённое. Нет ответа к 03:00 — ничего не публиковать, утром напомнить в 09:00.

## 2. День: публикация по очереди (09:00–22:00)

**Одна команда на пункт очереди:** `python3 tools/publish/job.py reel|thread КОД SHA ДАТА "ЧЧ:ММ" "Название"` — публикация, проверки, TikTok, уведомление и подпись в бот, отметка в очереди и README, commit+push (с 2026-10-02).

После «одобряю» — для каждого пункта очереди `send_later` на его время. В каждый момент публикации:
- Reels → `tools/instagram/publish_reel.py` (MP4 по ссылке на коммит) → сразу Stories (`--story`) → TikTok-черновик `tt.py draft`
  + в бот: «Ролик N вышел: ссылка. TikTok: черновик отправлен» и **отдельным сообщением только подпись с хэштегами** (≤5) — владелец копирует её в черновик; видео в TikTok без подписи не публикуется.
- Ветка → `tools/threads/publish_thread.py` (проверка цепочки `is_reply`) → карусель на сайт (ветка `claude/ai-ecommerce-automation-3n1lgz`,
  `docs/tiktok/media/T-NN/`, разрешение владельца 2026-10-01) → `tt.py photos T-NN EMPTY` (без описания) → в бот: «Ветка N вышла: ссылка».
- Ошибка → в бот сразу, с причиной; следующий пункт не задерживать.
- При каждом пробуждении — `tg.py inbox`: вопросы и команды владельца выполнять/отвечать.
- Вечером, после последней публикации, — к §1 (сборка следующего дня).
