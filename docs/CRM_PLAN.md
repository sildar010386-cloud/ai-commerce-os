# План своей CRM и приёма заказов на поток (владелец, 2026-10-22; строить — когда скажет владелец)

Цель: если пост/ролик соберёт 200–300 тыс. просмотров, не терять ни одного покупателя; видеть прозрачно, откуда клиенты; не зависеть от лимитов Claude; не платить Битрикс/amoCRM.

1. **Один вход — WhatsApp.** Во всех ответах и шапках профилей — ссылка wa.me с готовым текстом и меткой поста («Хочу отпариватель (T-105)») → источник клиента считается автоматически. В Threads личные сообщения через API недоступны.
2. **ИИ-продавец в WhatsApp (официальное подключение WhatsApp Business):** отвечает за секунды, только правдивые факты, собирает имя, телефон, город, адрес, количество → заказ в CRM; сложное/жалобы/торг — владельцу. На потоке — не на подписке Claude, а с оплатой ИИ за сообщения (центы за диалог) — платно, только с согласия владельца.
3. **CRM-панель:** заказы (новый → подтверждён → отправлен → получен, трек Казпочты, сумма, источник); продажи день/неделя/месяц; какой канал и пост приносят заказы; список «залетевшего» контента на повтор 2–3 раза в месяц (метод Калижарова); недельный контент-план с автопубликацией; остаток на складе.
4. **«Руки» без ИИ:** публикации по расписанию, сбор статистики и комментариев — обычный код на GitHub Actions (бесплатно), ключи — в секретах GitHub (владелец вносит сам). ИИ нужен только для текстов, картинок и ответов людям.

Порядок: WhatsApp + метки → панель CRM → ИИ-продавец → перенос публикаций на GitHub Actions.
Нужно от владельца: номер WhatsApp для бизнеса, способ оплаты, остаток и поставки товара.

## Уточнения владельца (2026-10-22, вечер)
- WhatsApp Business уже есть, два номера (основной + запасной на случай блокировки). Ссылка на WhatsApp уже стоит в шапке Instagram и Threads; в TikTok ссылку поставить нельзя до 1000 подписчиков — номер написан эмодзи.
- Метки источника: в шапке каждой площадки — своя ссылка wa.me с готовым текстом («Хочу отпариватель (Threads)» / «(Instagram)»); номер ссылки менять в одном месте CRM.
- Оплата: 100 % предоплата, ссылка на удалённую оплату от ИП (её же будет отправлять ИИ-менеджер).
- Вкладка «Контент» в CRM: план недели по дням и времени, статус каждого поста, автопубликация через GitHub Actions (без лимитов Claude) и кнопка «Опубликовать сейчас» (workflow_dispatch → tools/publish/slot.py), защита от дублей. Запасной вариант до CRM — кнопка «Run workflow» в приложении GitHub.
- Порядок: 23.10 — видео; следующая неделя — CRM (клиенты, заказы, источники, вкладка «Контент»); ИИ-менеджер — последним, когда пойдёт поток заказов.
