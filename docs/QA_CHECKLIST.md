# Проверка результата помощников (делает Opus перед отправкой владельцу или публикацией)

Не прошёл хотя бы один пункт — вернуть помощнику с конкретной правкой или исправить самому. «Почти хорошо» не отправляем.

## Любой текст
- [ ] Только русский язык, естественный, без канцелярита и «рекламного» тона.
- [ ] Нет цены. Нет обещаний, которых нет в `docs/DECISIONS.md` (только: 9 секунд, 2 в 1, без доски, складывается в маленькую коробку, бесплатная доставка Казпочтой). «Хранится на стене» — не выгода.
- [ ] Не противоречит последним решениям владельца (`docs/DECISIONS.md`, раздел Current state в `CLAUDE.md`).
- [ ] Формат, ситуация и зацепка не повторяют публикации последних 7 дней.

## Пост Threads
- [ ] 1–3 предложения, вся суть в первой строке, в конце вопрос на одно слово.
- [ ] Нет длинного тире «—». Эмодзи 0–2, хэштег 0–1. Нет списка советов.
- [ ] Продающий — история или шутка текстом, без фото и видео товара; «ПАР» — только в нашем ответе.

## Карусель TikTok
- [ ] 5–6 слайдов (максимум 6, владелец 2026-10-22), обложка с открытой петлёй, счётчик, лучший пункт последним перед CTA; CTA «Сохраняй и отправь…» (+ «ПАР» только в продающих). Охватные — без товара.
- [ ] Картинки — яркие ИИ-фото в стиле карточек маркетплейса (`tools/tiktok/carousel_photo.py`), не скрины из сырья; готовые слайды посмотрены глазами.
- [ ] Фото на слайдах соответствуют тексту (нет нашего отпаривателя на слайде «ДО: утюг» и т. п.), посмотрены картинки готовых слайдов.
- [ ] Не больше 5 хэштегов, факты правдивы.

## Ответ на комментарий
- [ ] По теме того, что написал человек, 1–2 предложения, дружелюбно, без спора, без цены, без «—».
- [ ] Интерес к покупке — приглашение написать «ПАР» или в личные сообщения.

## Публикация (после Haiku)
- [ ] В выводе есть id и ссылка (permalink), в очереди стоит done, коммит запушен.
- [ ] Не было дубля (до публикации пункт не был done).

## Отчёт владельцу
- [ ] Цифры сверены с файлом статистики, ничего не придумано, выводы следуют из цифр.
- [ ] Коротко, по-русски, без английских слов и технических имён файлов, где можно обойтись.

## Threads: строгое копирование (владелец, 2026-10-24 — главнее остальных пунктов про тексты)
- Охватный пост = оригинал слово в слово. Не менять голос (мужской остаётся мужским), эмодзи, опечатки, строки, слова. Английский оригинал — максимально дословный перевод.
- Продающий пост = оригинал слово в слово, заменён ТОЛЬКО товар на «ручной отпариватель» (и согласование слов). Удаляются только цена, валюта и названия магазинов/маркетплейсов.
- Повтор старого продающего «другими словами» — нельзя; нужен новый источник (добор через Chrome).
- Проверка: открыть строку оригинала в content/refs/hooks/* и сравнить с «## Пост 1» побуквенно; любое другое отличие — вернуть.
