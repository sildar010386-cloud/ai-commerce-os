## 1. Заголовки и хуки

### 1.1 Три слова: ЕСЛИ / ПОЧЕМУ / КАК (курс, владелец 27.10 и 31.10)
Не меньше половины любого набора хуков/заголовков начинаются с «Если / Почему / Как» (5 из 10, 3 из 5). Считать и писать итог перед отправкой. Подробно — `CONTENT_RULES_ARMAN.md` §2.

- Запрет — разрешённый тип хука для всех наших роликов (охват и продажа). Доля запретов в наборе — по решению владельца (пока не задана); правило «если/почему/как ≥ половины» остаётся.
- Сильнее всего «Что нельзя делать в…» и «Ни за что не…» (2,3–3,1 млн), когда тема — общая боль «для всех». Запрет в ролике, который выглядит как реклама, даёт мало (10 тыс.).
- Оформление запрета: ❌ и ‼️ в плашке, ЗАГЛАВНЫЕ буквы.
- **Наше правило (владелец 19.11): в каждом ролике заголовок = красный ❌ в начале + хук ЗАГЛАВНЫМИ белым по центру + три красных ❗❗❗ в конце** — подробно `docs/video/RULES.md`.

## 3. Как снимать и монтировать (разбор 18.11 + курс)
| Что | Как у Армана |
|---|---|
| Длина | лучшие ролики 20–90 с (Instagram медиана 62 с, 3 из 4 лучших ≤ 30 с; TikTok медиана 76 с). Слабые — 82–135 с |
| Формат охватных | TikTok: говорящая голова (15 из 15), часто диалог в кафе, показ экрана телефона; Instagram: кадры события, люди, голова |
| Простота | «снимать по-колхозному» — простые ролики набирают (курс/ролик 22.10) |
| Плашка-заголовок | весь ролик, крупно, жёлтая или белая (7/15 Instagram, 10/15 TikTok); заголовок с первого кадра (наше правило 27.10) |
| Субтитры | белые, по одному слову, ключевое слово — жёлтым |
| Финал | слово-призыв в конце и в подписи (у него «555»; у нас «ПАР») |
| Повтор удачного | ролик зашёл → переснять с тем же заголовком 3–4 раза в месяц (TikTok 11,5 млн → 8,7 млн; серия «Президенты» — 4 ролика) |
| Метод старта (курс, 22.10) | взять заголовки залетевших роликов конкурентов (100–300 тыс.), снять со своим текстом; свои придумывать после ~10 тыс. подписчиков |
| Не делать | > 90 с, один план без смены картинки, один шаблон с заменой слова, призыв в каждом ролике |

## 4. Продающие ролики
- Наша схема остаётся (владелец 15.11): товар на весь экран, владелец в кружке справа внизу, боль → решение кадрами товара → «ПАР», 25–40 с, стандартный монтаж. У Армана нет товара — поэтому у него в кадре лицо.
- Взять от Армана в продающие: заголовок-запрет (§1.2), плашка весь ролик, субтитры с жёлтым ключевым словом, слово-призыв в конце и в подписи.
