# Распределение работы между моделями (владелец, 2026-10-22)

Цель: недельный лимит не должен заканчиваться за 2–3 дня, качество не падает. Opus — дирижёр и проверяющий, рутину делают Sonnet и Haiku. Спрос за качество — с Opus.

## Кто что делает
| Помощник (`.claude/agents/`) | Модель | Задачи |
|---|---|---|
| Главная сессия (дирижёр) | Opus | Стратегия, новый подход, постановка задач помощникам, **проверка каждого результата** по `docs/QA_CHECKLIST.md`, всё, что уходит владельцу |
| `bikas-writer` | Sonnet | Тексты: посты Threads, карусели, подписи, черновики ответов на комментарии, черновики отчётов и разборов статистики |
| `bikas-researcher` | Sonnet | Тяжёлое чтение: разбор чужих роликов и постов, длинные документы, сравнение цифр, поиск неиспользованного сырья. Возвращает короткую выжимку |
| `bikas-publisher` | Haiku | Механика без решений: публикация одобренного точной командой, отправка каруселей в бот, сбор статистики, список комментариев, публикация уже утверждённых ответов, отметки в очереди, коммит/пуш |

## Правила дирижёра (Opus)
1. Сам не читает большие файлы и не делает механику, если это может сделать помощник. Сам — постановка задачи, проверка, решение.
2. Ничего от Sonnet/Haiku не уходит владельцу и в публикацию без проверки по `docs/QA_CHECKLIST.md`. Не прошло — вернуть помощнику с конкретными правками или исправить самому.
3. Тексты ответов на комментарии пишет `bikas-writer`, утверждает Opus, публикует `bikas-publisher` — Haiku тексты не сочиняет.
4. Встроенным помощникам (Explore, general-purpose) явно указывать модель `sonnet` или `haiku`, а не Opus.
5. Одна сессия — один день или одна большая задача. Длинную сессию на неделю не держать: всё нужное для продолжения — в `CLAUDE.md`, `docs/DECISIONS.md`, `docs/HANDOFF.md`.

## Задачи по расписанию (когда владелец вернёт публикации)
- Каждая публикация — **отдельная короткая сессия на Haiku** (`create_new_session_on_fire`, модель Haiku), самостоятельный текст задачи: точная команда, проверка «не дублировать», отчёт. Не будить длинную сессию Opus ради одной команды.
- Ежедневная сборка пакета: Sonnet пишет черновики, Opus проверяет и отправляет владельцу.
- Утренний отчёт: Haiku собирает цифры, Sonnet пишет черновой разбор, Opus проверяет выводы.
