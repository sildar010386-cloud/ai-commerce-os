# Журнал решений и фактов о бизнесе

Короткий источник правды для всех следующих сессий разработки. Обновляется при каждом решении владельца.

## Факты (2026-09-29)

| Тема | Факт |
|---|---|
| Страна / валюта | Казахстан, тенге (₸) |
| Юрлицо | ИП есть |
| Склад / отправка | Алматы |
| Доставка | Казпочта по всему Казахстану. Доставка «бесплатная» — заложена в цену (УТП) |
| Чек | 10,000–20,000 ₸; типично цена 10,000 ₸ при закупке ≤ 2,000 ₸ |
| Ниша | Без фиксированной ниши. Лучше всего на таргете продавались: здоровье, косметика, БАДы, кремы, мази. Раньше: товары для дома, кухня (овощерезки и т.п.). Задача — любая ниша и любой чек, если есть прибыль и масштаб |
| Менеджеры | Нет. Заказы обрабатывает владелец |
| Таргет | Уходим как можно быстрее; нужен срочный органический контент |
| Аккаунты | Есть TikTok, Instagram, Threads с подписчиками |
| Контент | Снимает владелец; также делает нарезки из готовых роликов. AI-видео дали 100–200 просмотров — не доверяем |
| Язык контента | Русский |
| Время владельца | Полная занятость проектом |
| Поставщики | Местные, Алматы; закупка небольшими партиями |
| Оплата | Счёт на оплату на ИП или ссылка на оплату |
| Казпочта | ~1,500 ₸ за посылку в среднем |
| Склад сейчас | Паровой утюг (отпариватель), power bank с беспроводной зарядкой |
| Аккаунты (детально) | Instagram ~1,500 подписчиков; Threads новый (от Instagram); TikTok новый, 2–3 ролика |
| Озвучка | ElevenLabs, клон голоса владельца (мужской) |
| Таргет | Отдельный проект, в эту систему не входит |
| Разработка | Claude пишет код; владелец сам выполняет технические шаги по инструкции. Фрилансер не нужен |

## Открыто

- Отпариватель: модель, закупка с доставкой до Алматы, подтекает ли
- Power bank: ёмкость, закупка; принимает ли Казпочта аккумуляторы
- Цены Kaspi по отпаривателю и кандидатам #1–#3 (проверка владельцем)
- Поставщики и цепочка закупки
- Регистрация (СГР) у ранее проданных БАДов; статус мазей (косметика или лекарство)
