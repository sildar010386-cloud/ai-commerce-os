# Запуск бота «Контент-студия» — пошагово

Время: ~1 час, один раз. Дальше обновления — одной командой.

> **Правило безопасности:** токены, пароли и ключи **никогда не отправляйте в чат** (ни мне, ни кому-то ещё). Вы вводите их только на сервере, в шаге 6. Пароли от Instagram, TikTok и Threads не нужны совсем: публикацию подключим через официальные API позже.

---

## Шаг 1. Создать бота (5 минут)

1. В Telegram откройте **@BotFather** → `/newbot`.
2. Имя: например, `Контент-студия`.
3. Username: латиницей, в конце обязательно `bot`, например `my_content_studio_bot`.
4. BotFather пришлёт **токен** вида `123456789:AA...`. Сохраните его в заметках телефона. **Никому не отправляйте.**

## Шаг 2. Получить api_id и api_hash (5 минут)

Нужны, чтобы бот принимал файлы до 2 ГБ (обычный бот — только до 20 МБ, а сырое видео с телефона весит больше).

1. Откройте **https://my.telegram.org** → войдите по номеру телефона (код придёт в Telegram).
2. **API development tools** → заполните форму: App title — `content studio`, Short name — `contentstudio`, остальное можно оставить пустым → **Create application**.
3. Сохраните **api_id** (цифры) и **api_hash** (строка). Тоже никому не отправляйте.

## Шаг 3. Арендовать сервер в Казахстане (15 минут)

Сервер работает 24/7: принимает сырьё, хранит библиотеку, позже будет монтировать ролики.

- Провайдер: любой казахстанский с VPS (например, PS.kz, Hoster.kz — сравните цены).
- Конфигурация: **Ubuntu 24.04**, **4 vCPU, 8 GB RAM, 100–160 GB SSD/NVMe**. Ориентир: ~15–30 тыс. ₸/мес.
- Доступ: по паролю root (или SSH-ключ, если умеете).
- После оплаты у вас будут **IP-адрес** и **пароль root**.

## Шаг 4. Подключиться к серверу (5 минут)

1. Установите **Termius** (телефон или компьютер, бесплатно).
2. New Host → Address: IP сервера, Username: `root`, Password: пароль root → Connect.
3. Появится чёрный экран с командной строкой. Все команды ниже копируйте туда целиком и нажимайте Enter.

## Шаг 5. Дать серверу доступ к коду (5 минут)

Репозиторий закрытый, поэтому сервер получает свой ключ только для чтения.

```bash
ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519 && cat ~/.ssh/id_ed25519.pub
```

1. Скопируйте строку, которая начинается с `ssh-ed25519`.
2. GitHub → репозиторий **ai-commerce-os** → **Settings** → **Deploy keys** → **Add deploy key**.
3. Title: `server`, Key: вставить строку. Галочку **Allow write access НЕ ставить** → **Add key**.

## Шаг 6. Установить бота (10 минут)

```bash
apt-get update && apt-get install -y git
git clone -b claude/ai-ecommerce-automation-3n1lgz git@github.com:sildar010386-cloud/ai-commerce-os.git /opt/ai-commerce-os
cd /opt/ai-commerce-os && bash scripts/install.sh
```

- На вопрос `Are you sure you want to continue connecting?` ответьте `yes`.
- Скрипт спросит токен бота, api_id, api_hash и ваш Telegram ID. **Токен и api_hash при вводе не видны на экране — это нормально**, просто вставьте и нажмите Enter.
- Telegram ID можно пропустить (Enter) — бот подскажет его сам.
- Установка займёт 3–7 минут. В конце появится таблица с тремя строками `running`.

## Шаг 7. Открыть доступ себе (2 минуты)

1. Напишите своему боту `/start`.
2. Если он ответит «Нет доступа. Ваш Telegram ID: 123456789» — выполните на сервере:

```bash
cd /opt/ai-commerce-os && bash scripts/set_owner.sh 123456789
```

(подставьте свой ID). Снова `/start` — бот поприветствует и покажет активный товар «Отпариватель (STM)».

## Шаг 8. Проверка

1. Отправьте боту 1–2 видео через **📎 → Файл** (так без сжатия).
2. Через несколько секунд придёт сводка: «✅ Принято: 2 видео (0 мин 48 сек) · Товар: Отпариватель (STM)».
3. `/library` — покажет, что лежит в библиотеке и сколько места свободно.

Напишите мне в чат «бот работает» — и начинаем следующий модуль.

---

## Как пользоваться каждый день

| Действие | Как |
|---|---|
| Отправить сырьё | Просто пересылайте видео, фото, озвучку в бота. Можно пачкой |
| Лучшее качество | 📎 → **Файл**, а не «Видео» (бот предупредит, если видео пришло сжатым) |
| Сменить товар | `/product` → кнопка |
| Новый товар | `/newproduct BRUSH Электрощётка` |
| Отправить файл в другой товар | В подписи к файлу: `#BRUSH` |
| Что в библиотеке | `/library` |

## Обслуживание сервера

| Задача | Команда |
|---|---|
| Обновить бота до новой версии (я скажу, когда) | `cd /opt/ai-commerce-os && bash scripts/update.sh` |
| Посмотреть логи, если что-то не так | `cd /opt/ai-commerce-os && bash scripts/logs.sh` |
| Добавить ещё одного пользователя | `bash scripts/set_owner.sh ВАШ_ID,ДРУГОЙ_ID` |

Если что-то пошло не так — пришлите мне **текст ошибки** из терминала (без токенов и паролей).
