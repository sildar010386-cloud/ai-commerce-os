## 1. Главный вывод по рынку

**Почти любой китайский гаджет уже есть на Kaspi за 4,000–7,000 ₸.** Покупатель из TikTok за 10 секунд проверяет цену. Поэтому модель «закупка 2,000 → продажа 10,000» работает только в одном из трёх случаев:

| Путь | Суть | Пример |
|---|---|---|
| **1. Ранний тренд** | Товар уже «взлетает» в Китае (Douyin), США (TikTok Shop) или РФ, но на Kaspi его ещё мало или нет | Окно 1–3 месяца, потом приходят конкуренты и цена падает |
| **2. Оффер сильнее цены** | Цена близка к Kaspi (+0–20%), но предложение лучше: комплект, подарок, гарантия обмена, бесплатная доставка, личная рекомендация | «Набор для зимней одежды», а не «ещё один отпариватель» |
| **3. Доверие к личности** | Покупают у человека, которому верят: «я проверил, работает» | Ваш личный бренд — долгосрочное преимущество |

**Вывод:** УТП каждого товара = **сравнение с Kaspi + оффер + доверие**. Эта проверка — обязательная часть карточки товара.

## 2. Позиционирование аккаунта (решает проблему «солянки»)

Вы не хотите превращать аккаунт в смесь случайных товаров, и при этом ниша не фиксирована. Решение — **зонтичный личный бренд**:

> **«Проверяю полезные находки для дома и жизни — показываю только то, что реально работает».**

- Любой товар (отпариватель, щётка, массажёр, органайзер) вписывается в одну понятную роль: вы — человек, который **тестирует и отбирает**.
- Экспертные ролики («на что смотреть при выборе…», «проверил 3 и оставил 1») укрепляют доверие и оправдывают цену выше Kaspi.
- Личные видео (10–20%) показывают, что за аккаунтом живой человек, а не магазин.
- Честность повышает доверие: иногда показывать товары, которые **не прошли** проверку («не покупайте это»).

## 3. Товары со склада

### 3.1 Паровой утюг / ручной отпариватель — **РЕКОМЕНДУЮ ПЕРВЫМ**

> Допущение: речь о ручном отпаривателе («утюг-отпариватель»). Если это классический утюг — сообщите, план контента изменится.

| Параметр | Оценка |
|---|---|
| Цены на Kaspi | Ручные отпариватели ~5,000–12,000 ₸ (Scarlett ~9,500, Tefal Access Steam+ ~12,000, noname ~8,000–11,000) |
| Демонстрация | **20/20** — «мятая рубашка → гладкая за 40 секунд» понятно без слов. Идеален для формата «до/после» |
| Сезон | Хорошо: пальто и пиджаки после шкафа, шторы, праздничная одежда, подарок на Новый год |
| Углы контента | 10+: утро перед работой, командировка, шторы без снятия, пиджак без блеска, деликатные ткани, мягкая мебель, подарок, сравнение с утюгом |
| Риски | Подтекание у дешёвых моделей (проверить на своём экземпляре); не обещать «убивает 99% бактерий» без сертификата |
| **Итог** | **75/100** = демонстрация 20/20 + спрос 17/25 + маржа 12/20 (зависит от закупки) + разрыв с Kaspi 8/15 + риски 18/20 |

**Цена и оффер (черновик):**

- Цена: **8,990–9,990 ₸** — в верхней половине Kaspi, оправдана оффером.
- Оффер: отпариватель + термоперчатка (или вторая насадка) + **бесплатная доставка Казпочтой по всему Казахстану** + **обмен в течение 14 дней**, если не подошёл.
- Позже, как допродажа: **«Набор для зимней одежды»** — отпариватель + машинка для катышков за 12,990 ₸ (дороже чек, выше прибыль).

**Экономика (нужна ваша закупочная цена):**

```
GP = 9,990 − закупка − 1,500 (Казпочта) − 300 (упаковка + перчатка) − 200 (оплата) − 300 (возвраты)
   = 7,690 − закупка
Закупка 2,500 → GP ≈ 5,200 ₸ ✅      Закупка 4,000 → GP ≈ 3,700 ₸ ⚠️
```

## 5. Что нужно от вас, чтобы закрыть анализ

1. **Отпариватель:** модель или фото, закупочная цена с доставкой до Алматы, есть ли подтекание при работе.
2. **Power bank:** ёмкость, закупка, есть ли вообще отправки аккумуляторов Казпочтой.
3. **Проверка на Kaspi** (1 минута на товар): для отпаривателя и кандидатов #1–#3 — минимальная цена того же или похожего товара и число продавцов. Скриншоты подойдут.
4. **Поставщики:** где закупаете (1688, оптовики Алматы, карго) — чтобы я считал закупку по вашей реальной цепочке.
